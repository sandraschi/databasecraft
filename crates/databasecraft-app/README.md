# `databasecraft-app` (L3 Native egui Relational Cockpit)

Ultra-lightweight (sub-30 MB RAM), pure-Rust native desktop workstation (`eframe`/`egui`) built for the 24/7 Executive/CFO Relational Cockpit.

## 11 Integrated Tabs

`Table Data`, `Relational Canvas`, `SQL & NLQ Console`, `Schema ERD`, `AI Copilot`, `RAG Vectors`, `Profiler`, `Doctor`, `Domain Constructor`, `Cross-Craft Export`, and `Alerts & Watchdog`.

## Highlights

- Universal Storytold 8-Menu Bar (`File`, `Edit`, `View`, `Insert`, `Modify`, `Commands`, `Window`, `Help`) + 5-Dialog Help Suite (`Ctrl+K` Palette, `F1` Shortcuts, Project Docs, Licenses, About).
- Continuous spanned spreadsheet matrix with drag-to-resize columns, drag-to-reorder headers, tri-state sorting, inline cell editing with Undo/Redo, compact joins, and smart cell formatting.

cargo run -p databasecraft-app -- --smoke
